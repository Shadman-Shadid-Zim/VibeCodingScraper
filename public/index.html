About Shadman's API

Automating a repetitive web task normally means writing custom code for every single website — impossible for non-programmers and brittle even for developers. Shadman's API removes the code entirely. Recording replaces writing a scraper, and a plain-language chat replaces writing input logic. One generic engine handles text fields, dropdowns, checkboxes, sliders, quantity steppers, calendar dates and typeahead search — using standard web & accessibility patterns, so it works across brand-new sites without a developer patching it each time.

Frequently Asked Questions

💬 Do I need to know coding?
Not at all. You just do the task once in a browser like you normally would, then run it later by typing what you want in plain English.
🌐 What websites can I record?
Almost any — online shops (Daraz, Rokomari), Google Forms, flight search, job sites, and more. Sites behind heavy bot-protection (e.g. some airline meta-search) may be blocked.
🎛️ What's a Variable vs a Constant?
A Variable is a field the AI changes each run (the book you search, the flight route). A Constant stays the same every time and is never mentioned (your name, phone, email).
🔒 Is my login safe?
Yes. Passwords are encrypted (AES-256-GCM) and never sent back to any user. Your Google/Facebook session is deliberately never captured. For login-required forms, "personal login" mode keeps your sign-in only on your own machine.
📊 What is an "interaction"?
Every time you record a workflow or run an API counts as 1 interaction. Your plan sets how many you get.
🛍️ Can I sell my APIs?
Yes! On a paid plan, publish to the marketplace and set your price. You receive what you set; buyers pay a 10% platform fee on top — shown transparently to both sides.
💳 How do I pay / get paid?
Payments use bKash Send Money to 01620888131. Plans and purchases are activated after we confirm the payment.
