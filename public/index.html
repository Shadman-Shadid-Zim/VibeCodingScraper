How to find the CSS Selector in 4 steps:

1

Open the target website in Chrome

Go to https://www.dsebd.org/ in a separate Chrome tab.

2

Right-click the search box → "Inspect"

A panel opens at the bottom showing the HTML code for that element.

3

Look for id= or name= in the blue-highlighted line

Examples of what you might see:

<input id="SearchBox" type="text" />

<input name="q" type="search" />

<input type="text" class="search-input" />

4

Translate what you saw into a selector:

id="SearchBox" → #SearchBox

name="q" → input[name="q"]

type="text" (no id/name) → input[type="text"]

💡 Confirmed for DSE (dsebd.org): Use #inputText — we inspected the page and that is the exact id= of their company search box.
